# GroundSurf Homebrew tap

Install the full-detail offline Mac wallpaper app:

```sh
brew tap takingbreath/groundsurf
brew install --cask takingbreath/groundsurf/groundsurf
```

macOS 13 or later, universal Apple Silicon/Intel binary. This is a third-party tap, not Homebrew's official catalog.

Preview: ad-hoc signed, not Apple notarized. macOS may block first launch. Read [Apple's guidance](https://support.apple.com/en-us/102445). No Gatekeeper override is included.

[Source, downloads, and credits](https://github.com/takingbreath/GroundSurf). GroundSurf by Akhilesh Khajuria; original generator by Lingdong Huang (MIT).
